# FieldDoc - Platform Repositori & Dokumentasi Foto Lapangan Vendor PLN

Sistem manajemen dokumen foto konstruksi ber-geotag (GPS Maps/EXIF) berbasis hirarki kontrak KHS, KR, Tahap Penagihan, dan PK.

## 🚀 Fitur Utama
1. Autentikasi & Management User (Admin Penagihan, Supervisor, Worker).
2. Master Data Kontrak Harga Satuan (KHS) & Kontrak Rinci (KR).
3. Pengelompokan Tahap Penagihan & PK/SPK Pekerjaan.
4. Upload Foto Dokumentasi Lapangan + Auto-Extract GPS Metadata (EXIF).
5. Auto Export Paket Berkas `.ZIP` Berstruktur Folder Bertingkat (`[KHS] / [KR] / [Tahap_X] / [PK] / [Foto.jpg]`).
